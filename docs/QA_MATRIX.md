## Browser defects corrected during implementation

- HTTP preview lacked crypto.randomUUID: replaced with crypto.getRandomValues IDs.
- Scheduled text-editor focus reopened text mode after inserting math: focus transition fixed.
- History ignored an empty-string snapshot due to a falsy check: fixed and regression tested.
- MathLive colorbox treated selected fractions as text: selection uses htmlClass decorations.
- Nested scripted group navigation lost true owner: stable structure ownership fixed.
- Logic suggestion row was too wide: fixed six suggestions; full sets in palette.
- Manual formula touch now activates and positions in one action; drag records a single manual touch.
- Undo restored content but lost active math context: surviving formula now keeps math mode.
- Tiny nested math scrollbars removed; overflow is handled by outer formula surface.
- Mobile PDF was horizontally oversized: screen-only fit scale preserves print dimensions.
- Function graph parser rejects unsupported input without JavaScript evaluation; adaptive sampling breaks undefined domains rather than drawing false lines across asymptotes.
- Graph images now use the existing image asset/history path, so insertion, undo/redo, persistence and PDF share one implementation.
- Palette selection after focused search initially lost the click when blur moved the sheet; palette buttons now retain focus through pointer down and complete the selection before closing search.
- Integral and infinity LaTeX shared the `\\in` prefix; logical-command classification now requires the complete command.
